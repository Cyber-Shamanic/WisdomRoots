## 🚀 הפעלה מקומית

1. חלצו את כל קובצי ה־ZIP לתיקייה אחת, תוך שמירה על מבנה התיקיות.
2. בתיקייה המכילה את `index.html` הפעילו שרת קבצים סטטי, למשל:

   ```bash
   python3 -m http.server 8000
   ```

3. פתחו בדפדפן: `http://localhost:8000/`.

**חשוב:** פתיחה ישירה של `index.html` בלחיצה כפולה (`file://`) עלולה לחסום טעינת מסמכי Markdown בדפדפנים מסוימים. לכן משתמשים בשרת HTTP מקומי, ללא התקנת תלות לפרויקט עצמו.
